# 图片水印工具

纯前端图片加水印工具：支持图片水印和文字水印，九宫格 / 平铺两种布局，可调大小 / 边距 / 不透明度 / 阴影 / 旋转，批量导出。所有处理均在浏览器本地完成，图片不经过任何服务器。

技术栈：Vue 3 + Vite + Element Plus + 原生 Canvas + JSZip，HEIC 支持（heic2any 按需加载）。

## 功能

- **两种水印**：图片水印（支持透明 PNG / HEIC）或文字水印（思源黑体 / 宋体、霞鹜文楷等字体可选，字号、颜色、描边可调；字体文件经 jsDelivr 按需加载）
- **两种布局**：单个水印按九宫格 9 位置摆放，或平铺铺满整图（防盗图）；支持 -180° ~ 180° 旋转、平铺间距调节
- **精细调节**：水印大小按目标图宽度百分比缩放、边距、不透明度、阴影
- **实时预览**：按显示区域 × 屏幕像素密度渲染，清晰度与原图一致；缩略图条切换预览图片；按住预览图临时查看无水印原图
- **上传**：点击上传 / 拖拽图片 / 整个文件夹拖入（自动递归读取），支持多选
- **导出勾选**：缩略图带勾选框，批量导出时可跳过不需要的图片
- **设置记忆**：水印图（IndexedDB）与全部参数（localStorage）自动保存，下次打开自动恢复；支持保存多组**命名预设**，一键切换水印方案
- **进度恢复**：未导出的图片列表自动暂存，意外刷新 / 关闭后重新打开会询问是否继续上次的进度，导出成功后自动清除
- **导出**：导出前弹窗选择质量（低 / 中 / 高（原图），仅对 JPEG/WebP 生效，PNG 无损），文件名模板（支持 {name} / {i} / {date}），可选保留 EXIF（默认关闭以清除拍摄位置等敏感信息），保留原格式与原图分辨率，多张打包 ZIP
- **深浅色主题**：右上角一键切换，跟随系统偏好、选择自动记忆
- **HEIC 支持**：iPhone 照片可直接使用（heic2any 按需动态加载，不影响首屏体积）

## 隐私

- 所有图片仅在浏览器本地处理，不会上传到任何服务器
- 导出默认**清除 EXIF**（拍摄位置 GPS、设备信息等敏感数据不会随图片外泄），如需保留可在导出设置中开启

## 开发

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build    # 产物在 dist/
npm run preview  # 本地预览构建产物
```

## 部署到 Vercel

- 方式一：代码推到 GitHub 后，在 vercel.com 导入仓库，框架会自动识别为 Vite（构建命令 `npm run build`，输出目录 `dist`），直接点部署即可。
- 方式二：命令行 `npm i -g vercel && vercel`。

纯静态站点，不需要任何环境变量或服务端配置。

## 测试素材

`test-assets/` 下有脚本生成的示例图（`target.jpg`、`target2.jpg`、`watermark.png`），可直接用来试用；`gen.ps1` 是生成它们的 PowerShell 脚本。
